# Frontend

Client applications for the MediCare platform.

## React.js (Web dashboards)

| App | Folder | Role |
|-----|--------|------|
| Clinic Admin Dashboard | `React/clinic-admin-dashboard/` | Clinic administrators |
| System Manager Dashboard | `React/system-manager-dashboard/` | Platform owner |
| Secretary Dashboard | `React/secretary-dashboard/` | Front-desk staff |

## Flutter (Mobile apps)

| App | Folder | Role |
|-----|--------|------|
| Patient Application | `Flutter/patient-app/` | Patients |
| Doctor Application | `Flutter/doctor-app/` | Doctors |

All apps connect to `http://localhost:3000/api/*` (api-gateway).  
Status: **planned** — scaffold each app in its folder when development starts.
