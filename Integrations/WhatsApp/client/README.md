# WhatsApp client

HTTP client for [Evolution API](https://github.com/EvolutionAPI/evolution-api).

**Canonical location** — synced into auth-service before build (`npm run sync:whatsapp`).

Used for: OTP delivery, staff credential messages, MFA, appointment reminders.

**Edit here only.** Auth-service copy: `Backend/NodeJS/microservices/auth-service/src/auth/services/whatsapp.service.ts`
